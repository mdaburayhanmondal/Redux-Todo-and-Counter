# Redux Toolkit Demo App

A simple, modern demonstration app built with **React**, **Redux Toolkit**, and **Tailwind CSS** featuring two main sections:

- **ToDo List** – Classic task manager with add, delete, and toggle complete functionality
- **Counter** – Advanced counter with increment/decrement, double, reset, custom amount input, and async random number fetching

Perfect showcase of modern Redux Toolkit patterns (slices, createAsyncThunk, loading/error states, real-time validation) in a single clean project.

## Features

### ToDo List

- Add new tasks
- Delete tasks
- Toggle task completion (strike-through)
- Dark/Light mode toggle
- Responsive design

### Counter

- Basic operations: +1, -1, Double, Reset
- Add custom amount (with real-time validation)
- Async random number fetching (with loading, success & error states)
- Add fetched random number to counter
- Disable controls during loading
- Temporary success messages
- Responsive & polished UI

## Tech Stack

- React (Vite)
- Redux Toolkit (slices, createAsyncThunk)
- React-Redux
- Tailwind CSS
- React Icons (BiPlus / BiMinus)
